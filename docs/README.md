# HTD AI SEO Writer Pro (`htd-ai-seo-writer-pro`)

Plugin WordPress tự vận hành, độc lập hoàn toàn với SoftViet, do HTD Digital quản lý mã nguồn, Prompt Engine, Credential Vault và quy trình phê duyệt.

- **Phiên bản hiện tại**: `0.8.0-dev` (Bản bàn giao phát triển — chưa đạt gate `1.0.0` production do chờ kiểm thử Docker/WP/MySQL staging và API thật).
- **Giấy phép**: GPL-2.0-or-later (`LICENSE`, `THIRD_PARTY_NOTICES.md`).
- **Yêu cầu**: PHP >= 8.1 (có OpenSSL AES-256-GCM), WordPress >= 6.0, tùy chọn WooCommerce & Rank Math.
- **Tài liệu chi tiết**: Xem thư mục `docs/`.
